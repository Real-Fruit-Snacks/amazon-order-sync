amazon-order-sync

Syncs your Amazon orders into local Markdown notes

Amazon's order history is a slow, paged website. This keeps a copy as plain Markdown files, one per order, with the product images next to them, so you can search, chart and keep it without Amazon. Everything runs on your computer.

$zip = "$env:TEMP\amazon-order-sync-windows.zip"
Invoke-WebRequest https://github.com/Real-Fruit-Snacks/amazon-order-sync/releases/latest/download/amazon-order-sync-windows.zip -OutFile $zip
Expand-Archive $zip "$env:LOCALAPPDATA\Programs\amazon-order-sync" -Force
Set-ExecutionPolicy -Scope Process Bypass; & "$env:LOCALAPPDATA\Programs\amazon-order-sync\install.ps1"
curl -fsSL https://github.com/Real-Fruit-Snacks/amazon-order-sync/releases/latest/download/amazon-order-sync-linux.tar.gz | tar xz && ./amazon-order-sync/install.sh
Then load the extension: brave://extensions → Developer mode → Load unpacked → the browser-extension folder the installer prints. Open your Amazon order history and press Sync Current Page.

What's in it

Three small parts, all on your computer

Local server

One Node.js file with no npm dependencies, on 127.0.0.1:27483. Writes one note per order under Orders/YYYY/MM-Month/, saves product images next to them, and serves the dashboard.

Browser extension

Reads your Amazon order pages and sends them to the server. Sync Current Page or Auto-Sync All Pages from its popup. Runs only on Amazon order and review pages.

Dashboard

Spend by month, every order searchable, price drops on things you bought, repeat purchases, and CSV or JSON export of the lot. Import your full history from Amazon's "Request My Data" export.

Headless sync

After a one-time login, the server can run your browser headless with the real extension on a schedule. No cookie scraping, and no browser window.

Windows tray app

Starts the server hidden, shows notifications, and has a menu for sync, login, the notes folder, the config and the logs. Start with Windows is a checkbox. On Linux, a systemd user service does the same job.

Review notes

Each item has a review section in its note. With an optional Gemini key the server drafts one for you to rewrite in your own words; the extension fills Amazon's form with what you saved, and you post it yourself.

Privacy

Nothing leaves your machine

Unless you add a Gemini key. Then, for each draft, it sends that product's name, brand and listing features, up to three public reviews of it, and up to three of your own posted reviews as style samples. Never your order numbers, prices or address.

  • The server binds 127.0.0.1 and refuses any request not addressed to 127.0.0.1 or localhost, which stops DNS rebinding.
  • It answers only its own dashboard, its own extension (a fixed ID) and local tools. Scripts on Amazon pages and other websites get 403.
  • The headless browser profile holds your signed-in Amazon session and never leaves your computer. Delete it to sign out.
  • Product images are fetched over http(s) only, must be real images, and are capped at 5 MB.

Configuration

config.json

%APPDATA%\amazon-order-sync\ on Windows, ~/.config/amazon-order-sync/ on Linux. The installer creates it and never overwrites it. Every key is in the guide.

KeyDefault
notesPath~/AmazonOrders
port27483; the extension expects it
autoSyncEnabledfalse; headless sync every autoSyncIntervalHours (24)
browserPathautodetect: Brave, Edge and Chromium before Chrome
geminiApiKeyempty; turns on review drafts

Tested on

  • Windows with Brave and the tray app: my own setup, daily
  • CI on every push: server tests on Ubuntu (Node.js 18 and 22) and Windows (Node.js 22), a tray build, and installer checks
  • Not tested: macOS, Firefox, Amazon sites other than amazon.com day to day

Known issues

  • Google Chrome ignores --load-extension since version 137, so headless sync needs Brave, Edge or Chromium. Manual sync works in Chrome.
  • When Amazon changes its order or review pages, sync or auto-fill can break until the extension is updated.
  • Don't add a --- line inside a review when editing a note by hand; it separates items.
